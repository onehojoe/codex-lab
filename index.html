What To Look For

The experiment is meant to make the automation behavior visible, with the prototype and preview images kept together.

Purpose

This prototype explores how route options can be generated and compared when a model has blocked zones. It can be read as a lightweight stand-in for circulation, routing, cable, pipe, or layout automation.

  • Draw start and end points directly on the canvas.
  • Add obstacle shapes or detect obstacles from an image.
  • Compare the shortest path with alternative routing patterns.
