자동화 실험실

Automation Lab

자동화 아이디어를 웹에서 직접 실행하고, 결과 이미지와 분석 리포트까지 한 곳에서 확인하는 공개 실험 공간입니다.

첫 실험 실행 페이지 설명 보기

무엇을 올리는 페이지인가

작은 프로토타입을 블로그 글의 첨부 링크로 끝내지 않고, 실제로 눌러 보고 검증할 수 있는 실행형 기록으로 남깁니다.

실험의 목적

자동화 스크립트, BIM 아이디어, 경로 탐색, 이미지 인식 같은 기능을 정적 웹 페이지로 정리합니다. 각 실험은 설명, 실행 화면, 결과 이미지, 배포 링크를 함께 갖고 있어 블로그에서 바로 연결할 수 있습니다.

  • 아이디어를 브라우저에서 실행 가능한 형태로 보관
  • 이미지와 짧은 설명으로 실험 의도를 빠르게 파악
  • GitHub Pages와 Cloudflare Pages에 연결 가능한 정적 구조
